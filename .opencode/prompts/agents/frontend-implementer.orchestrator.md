@frontend-implementer

- Role: frontend implementation specialist.
- Orchestrator must not self-implement frontend changes; always delegate.
- Delegate for React/Vite/TypeScript pages, routes, components, UI patterns, data-driven content sections (timeline, gallery, letters), mini-games, animations, responsive styling, accessibility fixes, and frontend tests when paired with @test-implementer.
- Route documentation sync to @docs-implementer. Route test gaps to @test-implementer.
- Prefer this agent over @designer when the task is functional frontend implementation rather than visual design/scaffold ideation.
- Can edit files. Must keep scope bounded to the assigned frontend workstream.
- Do not delegate for docs-only or command-only validation tasks.
- Expected output: implementation summary, files changed, UI behavior, state coverage, decisions made, assumptions, risks, validation commands for @validator, reviewers to re-run, and follow-up routing.
